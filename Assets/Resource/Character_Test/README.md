# Character Test Folder / 人物测试文件夹

This folder is dedicated to importing and testing new character FBX files.

**Purpose / 用途:**
- Import new character FBX files here for testing with the current Unity version
- This branch (`character_test`) is isolated from `main`, so any changes here will not affect the main project
- Once testing is complete and verified, assets can be merged into `main`

**Usage / 使用说明:**
1. Place your character `.fbx` files in this folder
2. Open the Unity project with your current Unity version
3. Test the character models in this branch
4. The `main` branch remains unaffected

**Notes / 注意事项:**
- This branch is a full copy of `main` as of the branch creation date
- Do NOT modify files outside this folder unless intentional for testing purposes
